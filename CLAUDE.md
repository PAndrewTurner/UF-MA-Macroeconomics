# CLAUDE.md — ECO5207 Macro Study App

Personal study web app for a graduate Macroeconomic Analysis course (UF ECO5207,
Garín–Lester–Sims textbook). Owner: Andrew. It turns a study guide into a
searchable site with flashcards and an interactive shock simulator.

## Run it

```bash
python3 build.py                 # bundle content/*.md into assets/content.js
python3 -m http.server 8000      # then open http://localhost:8000
python3 tests/smoke_test.py      # headless check of every view (needs playwright)
```

`index.html` also works opened straight from Finder after `build.py` has run
(the app reads `window.CONTENT` before trying to fetch the .md files).

## Layout

| Path | What it is |
| --- | --- |
| `content/*.md` | Source of truth for all written content (study guide, formula sheet, worked problem sets, practice exam). Exported from the Claude Docs study guide. |
| `assets/content.js` | Generated by `build.py`. Never edit by hand; rebuild after any content change. |
| `assets/render.js` | markdown to HTML (marked), ```latex fences to KaTeX, heading ids, and a pass that turns plain `Y_t`, `Y_{t+1}`, `C^d` into `<sub>`/`<sup>`. |
| `assets/search.js` | Section-level full-text search across the four documents. |
| `assets/flashcards.js` + `data/flashcards.js` | Flashcard UI and hand-written deck. Shock cards are generated from `data/shocks.js`. Progress lives in localStorage. |
| `assets/simulator.js` + `data/shocks.js` | Neoclassical-model shock simulator (labor market, production function, IS–Ys, money market). |
| `Class Material/` | The original course files (textbook chapters, lecture decks, problem sets). Source material for the content; git-ignored. |
| `assets/app.js` | Hash router (`#/guide?s=<heading-slug>`, `#/simulator?shock=Gt`), sidebar TOC, search box, theme. |

No build tooling or npm: plain HTML/CSS/JS, libraries from jsDelivr (marked 12, KaTeX 0.16).

## Content conventions (keep these)

- Every displayed formula is followed by a "where …" line defining each symbol.
- Math shorthand in prose uses `-->` for "implies/leads to" and `∴` for conclusions, not arrow glyphs like → or ⟹.
- Display formulas go in ```latex fences (bare TeX, no `$`). Inline math stays plain text (`Y_t`, `β(1+r_t)`), which render.js prettifies.
- The sign table in `data/shocks.js` is the theory answer from Ch 18 / Lecture 5. The simulator's numbers only illustrate it; if the model ever disagrees with a theory sign, fix the model, not the table.
- Lecture decks keep the credit spread f_t in investment demand (the current textbook edition drops it); the app follows the lectures.

## Simulator model (assets/simulator.js)

Labor demand `w = A(7 + bd(5 − N))`, labor supply `w = θ + bs(N − 5) − er(r − 3)`,
production `Y = 10A√N`, IS `Y = D − 2(r − 3)`, money `P = M / (Y(1 − 0.08 i))`, `i = r + π^e`.
Baseline: N = 5, w = 7, r = 3, P = 1. `er > 0` gives an upward-sloping Ys (PS 5, Ch 17 Ex 2).
